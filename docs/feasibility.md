# Netflix 双轨字幕可行性

状态：待真实 Netflix 验证，未通过阶段 0。

当前只有 WXT 工程骨架和只读播放器检测。内容脚本按需检查播放页、video 元素与标准 TextTrack 数量，不提取字幕内容，不修改字幕模式。TextTrack 数量不能代表 Netflix 完整字幕菜单；弹窗不会将它作为可选语言列表。

## 待验证

- 当前影片网页字幕菜单的完整轨道列表与稳定标识。
- 两种不同语言字幕能否同时获取，不依赖持续切换原生字幕。
- 字幕格式、请求来源、最小权限和可能的页面上下文桥接。
- 两种语言独立按视频时间同步，处理 seek、全屏与切集。
- 两部影片、Chrome / Edge，以及含三种语言影片的组合切换。

尚无可记录的真实 Netflix 浏览器版本、轨道格式或字幕 CDN 域名。不要据此文件宣称自动双语显示已支持。

若无法实现，按 PLAN.md 报告阻碍并重新讨论范围，不自动改成字幕导入或机器翻译。
