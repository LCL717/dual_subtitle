# Dul Subtitle v0.1.0

首个本地安装发行版，面向 Windows 桌面 Chrome / Edge。版本为实验版，未发布到扩展商店。

## 功能

- 从 Netflix 当前影片字幕轨道中选择两种语言，上下同步显示；区分 SDH 与字幕变体。
- 保存语言和启停偏好，刷新与下一集自动匹配字幕。
- 实时调整字号、背景透明度与文字阴影，默认透明背景。
- 授权读取本机字体、选择与预览字体，常见中日文字体显示本地名称。
- 使用 Netflix 播放器时间同步，支持广告后恢复同步的处理逻辑。

## 安装

1. Chrome 使用 `dul-subtitle-0.1.0-chrome.zip`，Edge 使用 `dul-subtitle-0.1.0-edge.zip`。
2. 将压缩包解压到一个固定目录，安装后保留该目录。
3. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
4. 点击“加载已解压的扩展程序”，选择解压后包含 `manifest.json` 的目录。
5. 刷新 Netflix 播放页，点击扩展，选择上方和下方语言并开启双语字幕。

已有本地安装：先记录当前加载目录，将新版解压内容替换到同一目录，在扩展管理页点击重新加载，再刷新 Netflix。保持原目录有助于保留扩展身份和本机设置，不要先卸载旧扩展。

## 验证与限制

38 项自动测试、类型检查及两款浏览器打包通过；用户已确认日英双语核心播放成功。广告、快速切集、全屏及字体权限等真实场景仍需进一步验收。

仅支持已实现的 IMSC/TTML 文本子集，不支持图像字幕和全部复杂排版。Netflix 私有接口变化可能影响功能。上下共用样式；字体读取受浏览器授权与 API 支持限制，原生下拉菜单可能忽略选项字体。

仅需 storage 扩展权限；设置和字体名称保存在本机，不上传字幕、字体或观看记录。需要已有 Netflix 正常播放权限。

## 校验

发行目录内 `SHA256SUMS.txt` 提供两个 ZIP 的 SHA-256 校验值，可用 PowerShell `Get-FileHash 文件路径 -Algorithm SHA256` 核对。
