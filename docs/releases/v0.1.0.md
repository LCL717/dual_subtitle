# Dual Subtitle v0.1.0

首个本地安装发行版，面向 Windows 桌面 Chrome / Edge。版本为实验版，未发布到扩展商店。

## 功能

- 第一字幕固定跟随 Netflix 原生字幕，第二字幕选择另一种语言；按具体轨道区分 SDH 与普通字幕。原生字幕关闭时暂停双语并提示选择。
- 保存语言和启停偏好，刷新与下一集自动匹配字幕。
- 实时调整字号、背景透明度与文字阴影，默认透明背景。
- 授权读取本机字体、选择与预览字体，常见中日文字体显示本地名称。
- 启动及广告后通过原生字幕匹配校准；用户已验证广告结束后无需显示控制条即可恢复。
- 简体中文 / English 界面；样式预览显示所选语言示例；双语运行时禁用 Start 按钮。

## 安装

1. Chrome 使用 `dual-0.1.0-chrome.zip`，Edge 使用 `dual-0.1.0-edge.zip`。
2. 将压缩包解压到一个固定目录，安装后保留该目录。
3. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
4. 点击“加载已解压的扩展程序”，选择解压后包含 `manifest.json` 的目录。
5. 刷新 Netflix 播放页，先在 Netflix 选择原生字幕，再在扩展选择第二语言并开启双语。等待可匹配的字幕切换后显示双语。

已有本地安装：先记录当前加载目录，将新版解压内容替换到同一目录，在扩展管理页点击重新加载，再刷新 Netflix。保持原目录有助于保留扩展身份和本机设置，不要先卸载旧扩展。

## 验证与限制

69 项自动测试、类型检查及两款浏览器生产打包通过。用户确认五项实机测试通过：日英双语显示、原生字幕关闭再开启、原生语言变化自动跟随、广告后不移动鼠标自动恢复、刷新或换集保留第二语言。此验证不覆盖所有影片、广告类型或浏览器版本。

仅支持已实现的 IMSC/TTML 文本子集，不支持图像字幕和全部复杂排版。Netflix 私有接口变化可能影响功能。上下共用样式；字体读取受浏览器授权与 API 支持限制，原生下拉菜单可能忽略选项字体。

无对白或匹配失败时保留原生字幕，校准失败后可手动拖动恢复。脱离原生字幕的独立时间源列入长期 TODO。运行中更换第二语言需先关闭双语再开启。

仅声明 storage 扩展权限，内容脚本在 Netflix 页面运行；设置和字体名称保存在本机。字幕资源由 Netflix 页面请求，扩展没有独立遥测上传。诊断记录手动开启，在页面内存保存并可下载；发行包不包含任何用户捕获日志。需要已有 Netflix 正常播放权限。

此包可用于首版手动分发安装；尚未提交商店，也不表示已通过商店审核。商店发布还需准备图标、截图、商店介绍及隐私说明等提交材料。

## 校验

发行目录内 `SHA256SUMS.txt` 提供两个 ZIP 的 SHA-256 校验值，可用 PowerShell `Get-FileHash 文件路径 -Algorithm SHA256` 核对。
