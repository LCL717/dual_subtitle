## 双语显示实验版（后续进展）

已实现页面内字幕请求（15 秒取消、4 MB 单文件限制）、IMSC 基本文本与时间解析、双轨叠加、关闭恢复、影片变更时停止、加载取消和过期响应丢弃。仅在两轨成功解析后隐藏 .player-timedtext；没有切换原生轨道。

暂不支持段内独立计时、图像字幕、顺序容器及复杂样式，遇到不支持的计时明确报错。仅保留内存 cue；不开启云服务。切集后自动恢复原生，需要重新开启。字号在开启时应用。
